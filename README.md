# Site do Pablo Barreto

Portfólio de Pablo Barreto, produtor cultural, parecerista e gestor de projetos no Rio de Janeiro.

Endereço do site: https://pablobarreto.com.br

## Como o site funciona

O site é estático, escrito em HTML, CSS e JavaScript. O GitHub Pages publica os arquivos da branch `main`. A Hostinger guarda o registro do domínio pablobarreto.com.br. Pelo DNS, ela aponta o endereço para o GitHub.

## Como atualizar o site

1. Abra o arquivo que você quer mudar neste repositório e clique no lápis para editar. Para enviar arquivos novos, use "Add file > Upload files".
2. Confirme com "Commit changes" na branch `main`.
3. Aguarde de 1 a 2 minutos. O GitHub Pages publica a nova versão sozinho.

## Estrutura dos arquivos

- `index.html`: página única do portfólio.
- `particulas.js`: animação de partículas do topo.
- `img/`: fotos, logos e imagens dos trabalhos.
- `CNAME`: informa ao GitHub Pages o domínio próprio. Não apague este arquivo.
- `.nojekyll`: manda o GitHub Pages publicar os arquivos exatamente como estão.
